Architecture soundness

Seven disciplines of a production AI architect, and where each one is running today.

These are the seven domains the Anthropic Claude Certified Architect – Professional credential assesses. The right-hand side of every card is not theory; it is a control, a metric or a document in a system above.

01Solution design & architecture

Pick the least autonomous pattern that solves the problem. Workflows when the steps are known, agents when they are not, an augmented single call when one is enough. Decompose by bounded context; a supervisor coordinates isolated specialists.

  • Flickhub-and-spoke manager over six one-job agents; typed state, durable checkpoint
  • Compassschema-constrained planner, read-only tools, arithmetic in code
  • Playgroundsix domain blueprints on one LangGraph runtime; same agent rendered into five frameworks
02Models, prompting & context

Choose models on the trade-off, not the leaderboard. Stable prefixes first so caching pays; prompts versioned like code; context loaded progressively, never as a monolith.

  • FlickClaude Opus primary, Azure OpenAI fallback; model pinned per run; prompts in an immutable store; token budgets per run, agent and model
  • CompassGPT-4.1 for planning, 4.1-mini where it is enough; verified exemplars retrieved as precedents at plan time
  • Playgrounddeterministic Economy / Workhorse / Premium router with savings recorded per call
03Integration

Tools scoped to one agent's job, audited for capability bloat. MCP where an integration should be discoverable and shared; identity checked at every tool endpoint; retrieval matched to the shape of the data.

  • Flickfive MCP servers, four to eight typed tools each; least-privilege token per server; source-system change stops at the MCP boundary
  • Compass39 read-only OData entities; role ∩ pack access; fail-closed bearer validation on the landing-zone door
  • Playground7,547-server MCP registry snapshot behind admin approval; the platform itself exposed as an MCP server
04Evaluation, testing & optimisation

Accuracy, latency, cost, safety and security measured together, because they trade off. Datasets that mirror real traffic including the tail. Code graders, model graders and humans, each where it is strongest. Every change passes evaluation before it meets a user.

  • Flick200-case analyst-labelled golden set weighted to the tail; per-agent metrics (F1, P@1, Brier, ECE); 5% canary, ramp, auto-rollback
  • Compass88-case battery, judge calibrated at 95% to humans, nightly canary that files its own issue
  • Quote Intelligence63 self-verifying assertions across four suites; any recorded comparison replays offline
05Governance, safety & risk

Four guardrail layers: input filters, system-prompt constraints, output validation, programmatic limits on what tools may do. Control strength scales with blast radius. Humans review the irreversible, the regulated and the low-confidence. Hallucination, injection, out-of-distribution input and over-reliance are designed for, not hoped against.

  • FlickContent Safety and PII redaction at ingress; critic on a second vendor; no auto-post above NZD 25,000 a line; residency and 7-year retention
  • Compassno write path exists; OWASP LLM & Agentic assessment with twelve adversarial cases nightly; "not visible to your role" is an answer
  • Playgroundpolicy, budget and ledger before every call; review gate that survives a restart; hard stops at 100% of budget
  • Dragonfruitseven HITL gates, a three-level trust ladder, a master kill switch; client-facing, financial and publishing gates never graduate
06Stakeholders & lifecycle

Structured discovery, decisions written down with their trade-offs, SLAs agreed before go-live, and handoff documents that let a client operate without me.

  • Flick22-page sponsor and architect debrief; approval thresholds set per environment with Finance
  • CompassADRs 0001–0006 plus factory ADR 0115; playbooks and a spec per packaged agent; landing-zone PRs merged by the platform owner; 28/28 acceptance with the person's own token
  • Playgroundtwo-page design document, deployment guide and in-product documentation hub
07Developer productivity & operations

Claude Code and agentic tooling configured for the team, CI that explains its failures, and operational issues that diagnose themselves.

  • CompassCI on every commit: Ruff, 24 unit tests, dependency audit, SBOM, secret scan; a red night files a diagnosed GitHub issue
  • Playground338 SKILL.md packs attachable to any agent; every run opens as a notebook; agent catalogue imported from everything-claude-code
  • All workbuilt with Claude Code; delivery logs and release notes in every repository

Approach

Evaluation first. Governance in code. Deterministic wherever money moves.

The three rules every system I ship follows, whether it is a client platform or a public repo.

01

Evaluation gates every release

Golden sets labelled by the people who own the process. An LLM judge calibrated against human review. Releases go out as canaries with automatic rollback, and production is re-tested every night so drift is found by the harness, not by a user.

Flick · 200-invoice golden set · 5% canary
02

Governance lives in code, not prompts

Read-only by construction. Least-privilege tool grants. PII redaction before any model call. Approval gates at the irreversible step. Audit trails on every decision, and OWASP adversarial cases that run alongside the functional battery.

Compass · 12 adversarial cases nightly
03

Deterministic core, generative edges

Every figure is computed in code. Decimal arithmetic, pure-code tripwires and a verifier on a different model, so the system can be wrong loudly but never quietly.

What it does

Finance no longer opens invoices one at a time. They open a chat. Every supplier-invoice line is matched against contract, purchase-order and meter evidence and closed with a confidence tier.

A LangGraph manager passes typed state through Parser, Matcher, Anomaly Detector, Reconciler and Reporter over five MCP servers. A Critic on a second LLM vendor rejects uncited claims. Green posts, amber queues, red drafts a dispute a human releases.

How it is proven

A 200-invoice golden set labelled by analysts gates every change overnight. 5% canary with auto-rollback. Idempotent ledger writes, circuit breakers, model fallback, PII redaction.
