# Satya Bonda — portfolio

Static site, no build step. Published with GitHub Pages at https://git-bonda108.github.io/

- `index.html` — home · `flick.html`, `compass.html`, `quote-intelligence.html` — case studies
- `styles.css` — design tokens as CSS variables; `script.js` — reveal-on-scroll and mobile nav
- `assets/` — résumé PDF, Open Graph image, favicon

Design source: Figma file "Satya Bonda — Portfolio". Typography: Anthropic Serif/Sans/Mono when installed, with Source Serif 4, Geist and Geist Mono as web fallbacks.
